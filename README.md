# VAJIRA IRB Website
**สำนักงานคณะกรรมการจริยธรรมการวิจัยในมนุษย์ คณะแพทยศาสตร์วชิรพยาบาล มหาวิทยาลัยนวมินทราธิราช**  
*(The Office of Vajira Institutional Review Board)*

เว็บไซต์และพิมพ์เขียวต้นแบบของสำนักงานคณะกรรมการจริยธรรมการวิจัยในมนุษย์ คณะแพทยศาสตร์วชิรพยาบาล (VAJIRA IRB) ตามอัตลักษณ์องค์กรใหม่ที่ทันสมัย เข้าถึงง่าย และเป็นมิตรต่อนักวิจัย

---

## 🌿 ทิศทางและภาพลักษณ์ (Brand Direction)
> *"Research for a Better Tomorrow, With People at the Heart."*  
> **ร่วมสร้างงานวิจัยที่มีคุณค่า เพื่อสุขภาพที่ดีของสังคม**

- **Trustworthy & Transparent:** ความน่าเชื่อถือ ความโปร่งใส ตรวจสอบสถานะได้ทุกขั้นตอน
- **Care & Support:** การดูแลผู้วิจัยอย่างใกล้ชิด พร้อมระบบอำนวยความสะดวก (VIRB Chatbot, Smart Checklist)
- **Empowering Research:** ส่งเสริมงานวิจัยที่มีคุณค่าและมาตรฐานระดับสากล
- **Social Well-being:** ปกป้องสิทธิ สวัสดิภาพ และความปลอดภัยของผู้เข้าร่วมการวิจัย

## 📂 โครงสร้างไฟล์ในโครงการ
- `index.html` : หน้าหลักของเว็บไซต์ (สามารถเปิดดูผ่านเบราว์เซอร์ได้ทันที)
- `style.css` : สไตล์ชีตและระบบ Design System ของ VAJIRA IRB
- `app.js` : สคริปต์การทำงานของระบบค้นหาสถานะโครงการ, เมนู และป๊อปอัป
- `assets/` : รูปภาพ แบนเนอร์ โลโก้ และองค์ประกอบกราฟิก
- `Visual guide line/` : ภาพแนวทางการออกแบบและคู่มืออัตลักษณ์
- `WEBSITE_GUIDELINE_AND_LINKS.md` : รายละเอียดโครงสร้างลิงก์และคู่มือระบบฉบับเต็ม
